设置页虚拟键盘与日历修复 · 一键应用到 Universal-Timer（Linux）
==================================================

修复的问题：
1. Windows 触屏设备上，刚打开设置后用手指点输入框，触摸键盘不弹出。
2. “目标时间”的日历弹窗太小、看不清，换成红黑主题，格子放大，方便手指点。

不需要 git，也不需要懂补丁。

【Linux】
1. 把这个文件夹整个解压出来，放进 Universal-Timer 项目文件夹里
   （就是有 src、assets、CMakeLists.txt 的那一层）。
2. 打开这个文件夹，在空白处右键 →“在这里打开终端”，输入下面这行并回车：
       bash apply.sh
   （也可以在文件管理器里双击 apply.sh，选“在终端中运行”。）
   工具文件夹放在别处也行，把项目路径跟在后面：bash apply.sh ~/文档/projects/Universal-Timer
3. 看到绿色的“完成！”后，重新编译运行。
撤销：在同一个地方运行 bash undo.sh

【它改了什么】
只改 src/ui/FullscreenPagesManager.h/.cpp 和 src/ui/SettingsContent.h/.cpp，都是新增代码：
打开设置时主动激活窗口，窗口激活时补发一次弹出键盘的请求；
给目标时间换一个自定义样式的日历弹窗。

改之前会把原文件备份到本文件夹的 backup 里。
如果代码和预期的不一样，它会提示是哪一步对不上，并且一个文件都不改。

如果打了补丁，Windows 上还是每次都不弹键盘，请检查系统设置：
“设置 → 时间和语言 → 输入 → 触摸键盘”里的“没有连接键盘时显示触摸键盘”。
