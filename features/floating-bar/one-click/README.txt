悬浮条淡化、点击穿透和 Win11 样式 · 一键应用到 Universal-Timer（Linux）
==================================================================

加上的功能（都在“设置中心 → 悬浮条设置”里，改了立即生效）：
- 鼠标移入时淡化（默认开）：鼠标移到悬浮条上时变得几乎透明，移开恢复，和 ClassIsland 一样；
- 鼠标点击穿透（默认开）：点击直接落到悬浮条下面的窗口，不会被挡住；
- 悬浮条不透明度（默认 100%）；
- 悬浮条样式：默认（就是现在的样子）/ Win11（仿 Win11，只换背景，文字不变）；
- Win11 样式深浅色：跟随系统 / 浅色 / 深色；
- 悬浮条距顶边距离（默认 0，贴着顶边）；
- 圆角还是用原来的“悬浮条圆角半径”。

不需要 git，也不需要懂补丁。

【用法】
1. 把这个文件夹整个解压出来，放进 Universal-Timer 项目文件夹里
   （就是有 src、assets、CMakeLists.txt 的那一层）。
2. 打开这个文件夹，在空白处右键 →“在这里打开终端”，输入下面这行并回车：
       bash apply.sh
   （也可以在文件管理器里双击 apply.sh，选“在终端中运行”。）
   工具文件夹放在别处也行，把项目路径跟在后面：bash apply.sh ~/文档/projects/Universal-Timer
3. 看到绿色的“完成！”后，重新编译运行。
撤销：在同一个地方运行 bash undo.sh
