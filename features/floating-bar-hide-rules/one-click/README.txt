悬浮条隐藏规则 · 一键应用到 Universal-Timer（Linux）
=================================================

加上的功能（在“设置中心 → 悬浮条设置 → 隐藏悬浮条”里）：
- 基础模式（默认）：可以勾“前台是最大化窗口时隐藏”“前台是全屏窗口时隐藏”，默认都不勾；
- 高级模式：点“编辑规则集…”，像 ClassIsland 一样用规则组和规则自由组合，
  可以按前台窗口的标题 / 类名 / 进程 / 状态、时间段、星期、距目标时间剩余天数来隐藏悬浮条。

需要先应用“悬浮条淡化、点击穿透和 Win11 样式”（features/floating-bar 里的一键包）。
没应用的话，这个工具会提示，并且一个文件都不改。

【用法】
1. 把这个文件夹整个解压出来，放进 Universal-Timer 项目文件夹里
   （就是有 src、assets、CMakeLists.txt 的那一层）。
2. 打开这个文件夹，在空白处右键 →“在这里打开终端”，输入下面这行并回车：
       bash apply.sh
   工具文件夹放在别处也行，把项目路径跟在后面：bash apply.sh ~/文档/projects/Universal-Timer
3. 看到绿色的“完成！”后，重新编译运行。
撤销：在同一个地方运行 bash undo.sh

【注意】
Linux 上要用前台窗口相关的规则，编译时需要 libxcb 开发包（Debian / Ubuntu：sudo apt install libxcb1-dev，
一般装 Qt 开发包时已经带上了）。没有的话也能编译，只是这类规则不生效。

改之前会把原文件备份到本文件夹的 backup 里。
如果代码和预期的不一样，它会提示是哪一步对不上，并且一个文件都不改。
