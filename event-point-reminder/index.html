EVENT POINT ① 现有：顶部倒计时胶囊
T−4.00s

Qt 实现对照（全部是 QPainter 能画的）
  1. 窗口：沿用 FullscreenPagesManager 的 FramelessWindowHint | WindowStaysOnTopHint | Tool + WA_TranslucentBackground，全屏大小，重写 paintEvent。
  2. 时间轴：一个 QVariantAnimation（0 → 总时长 ms，线性）驱动 m_t，valueChanged 里 update()；各图层用 QEasingCurve(OutCubic…).valueForProgress() 算自己的进度。拖动时间轴就是在设 m_t。
  3. 胶囊 → 红线：就是现有 m_fadeOutAnimation1 的收窄，然后用 fillRect 把 5px 线拉到满屏高。
  4. V 形红门：QPainterPath 六边形 + fillPath；门上的黑色时间先 setClipPath(门) 再 drawText，两扇门各画一次，字就被接缝切开。
  5. 四段圆环：QPen(宽度, Qt::FlatCap) + drawArc(rect, start*16, span*16)。注意 Qt 以 3 点钟为 0°、逆时针为正。
  6. 60 格刻度：translate 到圆心，循环 rotate(6) + drawLine；扫红只是按序号换笔色。
  7. 内圈虚线：QPen::setDashPattern + setDashOffset(m_t * k)。
  8. 冲击波：drawEllipse(center, r, r)，笔宽和 alpha 随进度衰减。
  9. 红色光晕：QRadialGradient 填充，不需要模糊滤镜。
  10. 角落三角 / 顶部标记：drawPolygon(QPolygonF)，闪烁节奏与现有方块相同（亮 500ms / 灭 500ms）。
  11. 斜纹警示带：setClipRect 后循环画平行四边形，x 偏移随 m_t 走。
  12. 红块擦除文字：setClipRect(已揭示区域) + drawText，再 fillRect 红块；字距用 QFont::setLetterSpacing。
  13. 收尾：直接复用 FadeOutAnimation（windowOpacity，1000ms，InCubic）；声音复用 QSoundEffect + countdown.wav。
